# Massey-University_2026
To what extent do sector-level excess returns persist through time in Australian institutional direct-property markets, how does sector persistence differ across the office, retail and industrial property sectors, and how can observed cross-sectional variation in return and valuation measures help interpret those persistence patterns?

## Repository Contents
 
/code
Analysis scripts
 
/outputs
Generated tables and persistence metrics
 
/documentation
Appendix documentation and reproducibility information
