# Persistence in Australian Commercial Property Returns
 
## Research Question
 
To what extent do sector-level excess returns persist through time in Australian institutional direct-property markets? How does persistence differ across the Office, Retail and Industrial sectors, and how can variation in return and valuation measures help explain those differences?
 
## Overview
 
This repository contains the code, outputs and documentation supporting a Master of Business Studies research project examining persistence in Australian commercial property returns.
 
The analysis investigates:
 
- Sector-level excess return persistence
- AR(1) persistence and half-life estimation
- Stationarity testing
- Predictive regressions using macroeconomic variables
- Cross-sector comparisons
- Office-sector regime analysis

## Data
 
The underlying Property Council of Australia / MSCI dataset is proprietary and is therefore not included in this repository.
 
Researchers with access to the underlying dataset should be able to reproduce the analysis using the code and documentation provided.
 
## Key Methods
 
- Augmented Dickey-Fuller (ADF) tests
- Autoregressive AR(1) models
- Half-life estimation
- HAC-robust regressions
- Variance Inflation Factor (VIF) diagnostics
- Ljung-Box residual diagnostics
